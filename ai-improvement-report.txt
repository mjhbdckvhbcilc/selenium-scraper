## Security Considerations

All `script` tags in HTML should have the appropriate CORS headers and avoid inline styles. 

### Example of a script tag with CORS headers:

```html
<script src="https://cdn.jsdelivr.net/npm/some-script@1.0.0/dist/someScript.js" 
        integrity="sha384-..."
        crossorigin="anonymous"></script>
```

### Data attributes in HTML for accessibility and safety:

Use data attributes for dynamic content:
```html
<div id="my-content" data-some-value="value">
    This is some text.
</div>
```
