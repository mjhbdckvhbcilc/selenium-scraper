# selenium-scraper

## Introduction
This repository contains a Selenium-based web scraper. It allows you to extract data from websites by navigating through HTML pages and extracting desired data.

## Getting Started
1. Ensure you have Python and Selenium installed on your system.
2. Clone or download this repository.
3. Install the required dependencies:
   ```
   pip install requests
   ```
4. Run the script:
   ```
   python scrape.py
   ```

### Updated `scrape.py` (Main Scraper Script)

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
import requests

# Basic Error Handling
try:
    driver = webdriver.Chrome()  # Ensure to install ChromeDriver
except Exception as e:
    print(f"An error occurred: {e}")

# Example Usage
def scrape_website(url):
    driver.get(url)
    # Example: Extracting all h1 elements from the webpage
    elements = driver.find_elements(By.TAG_NAME, "h1")
    for element in elements:
        print(element.text)

if __name__ == "__main__":
    url = "http://example.com"
    scrape_website(url)
